# 排查失败的推理请求

从第一个没有产出预期结果的阶段开始排查，保留配置 ID、资源校验文件、请求画幅和该阶段的报错。

## 设备与资源 {#startup}

在实际 worker 环境运行 `nvidia-smi` 和 `vflash doctor`。能看到显卡后，用相同配置与设备编号运行 `vflash plan`。校验文件被拒绝时检查文件是否移动、适配器与主干修订是否匹配，修复清单后重新生成校验文件。

## 请求被拒绝或内存不足 {#memory}

同时核对模式、宽高、时长、参考图数量及声音配方。在同一配置下测试最小已验证请求，记录峰值出现在文本编码、去噪还是解码。每次只降低一个维度或一个阶段的预算，然后分别测量显存和主机内存。

## 任务完成但效果不符 {#quality}

查看多个原尺寸帧及结尾，收听实际交付音轨。核对输入顺序，并区分首帧与外观参考。源片编辑要在相同时刻比较主体大小、接触与动作，也要检查帧数、音轨与显示比例。反馈时附最小可复现输入、运行版本及配方。
