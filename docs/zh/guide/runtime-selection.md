# 按输入和交付物选择运行时

| 手头的输入 | 要得到的结果 | 入口 |
| --- | --- | --- |
| 文字、首尾帧或有序参考图 | 使用固定配置生成本地 MP4 | [H3Pipeline 或 CLI](./complete-pipeline) |
| 文字或首帧，以及准备好的 Pika 权重 | 六步画面推理，可用联合音轨或独立 Larry 声音补采 | [PikaAVRuntime](./pika-flex) |
| 人物或商品照片 | 新镜头沿用照片中的外观 | [PikaReferenceAVRuntime](./pika-reference-weights) |
| 已有视频和目标外观 | 在原动作的时间线上编辑一个窗口 | [Remake](./remake) |
| 已编译的条件张量及匹配配置 | 供自有解码器使用的潜变量 | [原生 HTTP 接口](../reference/http-api) |

## 决定参考素材的作用

首帧固定开场构图；首尾两帧还会约束结尾。外观参考图提供人物、服装或商品设计，仍可生成不同的镜头。若要把佩戴中的手表改成酒红表盘，同时保留手腕转动，应选源视频编辑，明确指出表盘和要保留的表壳。

## 分配显卡与资源

为选定运行时核对[实测显卡和显存](./profiles)。准备权重的 Pika 和原版 BF16 Pika 各有独立权重与 Python 环境。服务端连续使用同一模型时，可以分配设备后一次准备资源，随后[复用会话](./python)。应用层负责保存原始输入、成片和历史任务。
