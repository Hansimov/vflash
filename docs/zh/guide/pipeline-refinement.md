# 精修生成音轨

<span id="optional-audio-only-six-step-refinement-source-main" aria-hidden="true"></span>


已支持的四步混合 I2VA 配方可用 AudioRefinementRequest 冻结视频，再运行六步音频精修。需提供匹配的原模型时序和表、与画幅相同的首图、生成音频设置及兼容单卡。试听对白时机和环境声是否改善。人脸重绘另需遮罩与权重。

[查看此实现的详细配方与测量记录](https://github.com/Hansimov/vflash/blob/v0.28.0a8/docs/zh/guide/pipeline-refinement.md)
