# 版本更新

## 0.22.0

新增`ReferenceAVRuntime`，在完整96 GiB SM120显卡执行原始FL／Larry分段流水线。
默认前4步Larry、后6步原始视觉，采用Veda44／6；随后以12步Larry生成H3原生声音，保留完整视频。
整合提示编码复用、空间视频KV、QKV融合及与官方解码的有界重叠。

范围：精确画布首图、5秒、至多2×1024²像素、最长边2048；显式加载固定上游源码、原始行FP8矩阵、
时间表及Larry资产。不会自动回退到完整Sage；原有hybrid档位和已受理请求保持既有合同。
见[资产、执行和质量范围](segmented-av)。

应用执行入口在400W PRO6000 Blackwell Server（95.59GiB）交付两条5秒视频：1024×1024对白
101.770秒，1920×1080动作228.338秒。包括条件、两个采样阶段、官方解码、编码及精确画布交付；
两次独立进程初始化17.09／16.17秒，采购、资产传输与上传另计。两条均为120帧、32kHz双声道，
核验全部注意力调用和声音阶段画面潜变量保持。这是交付验收，不新增完整Sage对比或同卡四步速度结论。

## 0.21.0

图像沿目标面积match尺寸，视频沿官方CFR24几何；schema 6绑定两种条件并校验组合前缀，schema 1–5保持原合同。
参考缓存加入有序图像身份与目标画布，使同一动作导引搭配不同外观时保持正确的条件归属。

默认完整空间视频。显式`reference_video_profile="spatial-half"`只池化最后一份视频latent空间网格，
此前外观图latent与全部已编码视频时间位置保持；完整缓存继续用于后续full请求。
输出保持五秒、最多1,048,576像素。用法见[组合参考](../guide/complete-pipeline#reference-video)。

首批证据是一张外观图和五秒CPU双人物递交道具预演，交付960×544／120帧，四步采样、Veda 44/6、
原生联合音频与web-v1交付：

| RTX 4090 48 GiB，BF16环、Torch密集注意力 | 280.706秒 | 168.883秒 | 59.060／90.092／18.383秒 |
| RTX PRO 6000 Blackwell Server，常驻FP8、SageAttention2 | 110.342秒 | 79.395秒 | 35.187／31.809／11.410秒 |

完整调用另计会话初始化和应用传输；SM120两次使用不同缓存宿主与冷编码状态，初始化33.843／19.981秒。

完整画面采样与接触序列保留人物外观并完成交接。当前属于单场景的近似动作控制证据，
其他动作、风格和三图负载继续分别确认。简洁／细化I2VA提示也完成了这个简单动作，按具体控制需要使用动作参考。
现有音频优化默认与资格范围保持。

## 0.16.1

`VFLASH_SM120_RESIDENT_GIB`可调低SM120常驻权重的显存门槛（默认90，可取24–90）。只服务实测峰值能放进

## 0.16.0

SM120上的`veda_dense_backend="sageattention2"`成为一个整体INT8 Q·K / FP8 P·V策略：除密集边缘层
（SageAttention 2.2.0 CUDA）外，Veda稀疏层的P·V也改用FP8。遍历、掩码、块选择与INT8 Q·K不变；V按头×通道
量化为e4m3，FP32累加。启动自检限定稀疏内核相对Veda原内核的误差（<5%），不做静默回退；回执新增
`sparse_precision`。其他后端、默认值与档案均不变。

不据此资格更大/更长SM89音频请求，不声称达到15%附加耗时或普遍改善音质，
既有几何与容量限制保持。

## 0.11.0

新增可选的仅音频六步修复，以约0.5MP空间条件保留原视频和全部时间位置，使用匹配调制表与解码余量保护。
要求显式选择单卡常驻hybrid I2VA、Veda 44/6；进度区分四步主生成和额外六步，默认行为不变。
独立的原生/文本FP8工厂与完整上下文按行分块减少集成方重复实现，不下载权重或扩大准入。

两组独立高清场景通过新音频接口及公共FP8工厂复现全部画面与交付PCM；另两组较小画布的
人脸/音频联合请求保持此前最佳人脸画面，并在人脸拼接中保留已修复音轨。
这是限定RTX PRO 6000 Server集成证据，私有扩展容量、应用资产和生产采用另验。
可选源场景条件复用仍保留明确的实验资格边界，不随包提供模型权重。


## 0.10.0

新增显式`batch2-fp16-norm-reuse-untiled`人脸编码配置，支持512方形、124帧输入。
移除重叠空间编码块，保留时间块复用，成功或失败均恢复模型状态；普通编码及MP4/RGB默认保持。

约48GiB的RTX4090上三个集成场景均减少完整人脸阶段耗时。精确公开配置另在一个场景中复现
私有原型全部120帧最终RGB；这仅证明与该原型一致，并不等同此前分块编码器。
空间上下文、归一化和部分细节改变，显存增加，计时与质量边界见完整流水线文档。
不新增修复模型、权重或应用调度。wheel、源码包和两类镜像已发布，接入应用仍需显式选择；
发行不会自动更改其已部署配置。
