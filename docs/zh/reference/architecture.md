# 引擎架构

一条成片要经过条件编码、去噪和媒体交付三个阶段。所选 API 决定由引擎负责哪些阶段。

## 从输入到画面 {#data-path}

完整流水线先依据配置校验请求，编码提示和素材，再采样音画潜变量，最后调用 VAE 解码并编码 MP4。原生会话从编译过的条件张量开始，输出采样后的潜变量。Pika 与 Remake 各自使用独立的执行约束和资源清单。

## 到哪里修改实现 {#sessions}

| 关注点 | 源码位置 |
| --- | --- |
| 配置与设备放置 | `catalog.py`、`contracts.py`、`planner.py` |
| 权重转换与完整性 | `compiler/`、`model_assets.py` |
| 原生模型运算与生命周期 | `native/` |
| 请求组合与阶段资源 | `pipeline/` |
| 编码器及解码器接入 | `adapters/`、`media/` |
| HTTP 受理与取回结果 | `server.py` |

模型计算与服务传输分离。账号、计费、用户历史与持久调度由应用层维护。

## 分阶段测量

将初始化耗时与重复请求分开记录。比较内核改动时固定资源、设备、种子、输入和解码器，同时检查最终画面、声音及中间数值误差。参见[性能测量](./benchmarks)。
