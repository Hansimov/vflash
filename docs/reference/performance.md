# Measure a complete inference request

Measure the first request after process start and several warm requests with one loaded owner. Record device and host peak memory, conditioning, denoising, audio refinement, decode and MP4 write time. A kernel speedup affects total latency only in proportion to its share of that path. Compare output frames and sound at the exact timestamps requested. See [hardware measurements](./benchmarks) for concrete examples.
