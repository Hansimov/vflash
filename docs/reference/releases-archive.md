# Find an earlier release

Open [GitHub Releases](https://github.com/Hansimov/vflash/releases) to download an older wheel or check its release date. Use the documentation at the same Git tag for commands, schemas and hardware qualifications. The [current upgrade guide](./releases) covers changes since the previous stable release.
