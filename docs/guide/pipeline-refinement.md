# Refine generated sound

For the supported hybrid four-step I2VA recipe, AudioRefinementRequest can add six audio evaluations while freezing the completed video. Supply the matched original-model schedule and tables. Generated sound, one same-canvas first image and one compatible device are required. Compare speech timing and environmental sound with the baseline. Face repaint is a separate optional pass with its own masks and weights.

[Read the versioned recipe and measurements](https://github.com/Hansimov/vflash/blob/v0.28.0a8/docs/guide/pipeline-refinement.md)
