# Upscale a finished video

FlashVSR upscales a delivered file with its own source and weights. Save to a separate path and compare texture, faces, lettering and motion at native size. The older STCDiT path performs same-size restoration. Both can repaint detail. The pinned versions, licenses, memory settings and execution examples remain in the recipe below.

[Read the versioned recipe and measurements](https://github.com/Hansimov/vflash/blob/v0.28.0a8/docs/guide/restoration.md)
